浏览器用例 12/12 通过，总时长约 28.3 秒；全过程峰值屏上 225 条、排队 300 条、缓存像素内存 28.75 MiB。另有 Node 前端离线回归 12/12 和 Python 后端回归 13/13 通过。

SSE 服务端每客户端仅保留最近 500 个事件，因此 1200 条突发中的一部分会先在服务端淘汰，浏览器的丢弃计数不包含这部分。内存数值为 RGBA 像素估算，不是浏览器进程总内存。帧间隔指标仅代表本机这一组负载，没有作优化前后的性能倍数比较，也不代表移动设备、其他浏览器或线上论坛的表现。
